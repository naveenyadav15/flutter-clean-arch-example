# flutter-clean-arch-example

Minimal Clean Architecture example with BLoC and DI.

## Quick start
1. `flutter pub get`
2. `flutter run`

## Architecture
- `domain/` — entities, usecases, repository interfaces
- `data/` — models, datasources, repository implementation
- `presentation/` — pages & blocs
